# rusnaptic
Полный русский перевод для демо-версии SNAPTIC (Катсцены, диалоги, текстуры).

Автор русификатора: RedL1zar




Для работы необходим GDPatch. Обычно он встроен в full релизные версии, но из-за него могут жаловаться антивирусы. Для проверки самого перевода можете установить его отдельно в only версиях.
